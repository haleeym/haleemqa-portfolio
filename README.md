About Me

I'm a QA Engineer specializing in manual functional testing, cross-browser and localization checks, and defect investigation.

My work is proof you can open: structured black-box testing on live web and mobile products, an internship at Sysbit Tech, and a group project where I led five testers. Every project comes with the edge cases I found, the steps to reproduce them, and the documentation behind them.

I see QA as bridging the gap between product managers and engineering teams — translating complex user edge cases into clear, structured bug tickets so developers fix critical issues faster and ship with confidence.
